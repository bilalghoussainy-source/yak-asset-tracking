⚡ Quick Setup — First Time Only

1Go to supabase.com → Create a free project (one project covers ALL clients)
2In your project: SQL Editor → Run this: create table asset_tracker (key text primary key, value text, updated_at timestamptz default now());
3Go to Project Settings → API → copy your Project URL and anon/public key below
4Paste them into the Supabase Connection fields below and click Connect & Save
5Sign in at your site root URL (/). Add App users below (admin vs client). Share https://your-app.vercel.app/ — clients are sent to their workspace after login.
